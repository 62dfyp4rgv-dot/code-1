# iOS build & distribution

> **Verification status: UNVERIFIED.** The authoring environment was Linux with no Xcode, no Simulator and no device.
> The Swift sources and `project.yml` were written carefully but **have never been compiled or run**. Treat the first
> macOS build as a debugging session, not a formality. What *is* verified: the web app that the shell hosts runs in desktop
> Chromium with iPhone viewport/touch emulation (see TESTING.md). Chromium ≠ WebKit; layout, IndexedDB quota behaviour, audio
> unlock, safe-area handling and performance can all differ.

## Option A — PWA (no Apple account needed)
1. `npm run serve` (or host `app/` on any static HTTPS host; service workers need HTTPS or localhost).
2. Open in Safari on the iPhone → Share → **Add to Home Screen**. The app runs full screen with `manifest.webmanifest`, caches
   assets via `sw.js` (`VERSION` constant — bump on release), and works offline after the first load.
3. Limits: iOS can evict PWA storage after long non-use; use *More → Saves → Export* for backups.

## Option B — Native shell (WKWebView)
Prerequisites: macOS, Xcode ≥ 15, [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`), an Apple ID (free account is enough for a device build; paid Developer Program needed for TestFlight/App Store).

```bash
bash tools/ios-sync.sh            # copies app/ → ios/ModernAge/www (service worker intentionally omitted)
cd ios && xcodegen generate       # creates ModernAge.xcodeproj from project.yml
open ModernAge.xcodeproj
```
In Xcode: select the *ModernAge* target → Signing & Capabilities → choose your Team (`DEVELOPMENT_TEAM` is blank in `project.yml`), change the
bundle id `com.example.modernage` to one you own, choose an iPhone Simulator or device, **Run**. Unit tests: ⌘U (`BundleSchemeHandlerTests`).

How it works: `GameViewController` creates a `WKWebView` that loads `app://localhost/index.html`; `BundleSchemeHandler` serves files from the
bundled `www/` folder (so `fetch`, IndexedDB and module scripts behave like a real origin and nothing touches the network). The JS bridge
exposes `haptic` (UIImpactFeedbackGenerator) and `exportSave` (share sheet).
